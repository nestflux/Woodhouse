Path to Production

Everything you need to go from finished codebase to live product. API keys, deployment steps, and verification checklist.

1. API Keys & External Services

Core AI — Required for any AI features
ANTHROPIC_API_KEY Anthropic Edge Functions
Powers every AI call in the system: resume parsing (Haiku), pre-screen filtering (Haiku), 5-dimension job evaluation (Sonnet), resume tailoring (Sonnet), cover letter & application answer generation (Sonnet), and all AI assist features (summary, skills, achievements). Without this key, the entire pipeline is inert.
console.anthropic.com → API Keys
Job Discovery — Required for automated job search
SERPAPI_API_KEY SerpAPI Edge Functions
Primary search engine. The Discovery Agent queries Google Jobs via SerpAPI — searches by role, location, country, and keywords from each user's search preferences. Returns structured job listings for evaluation.
serpapi.com
JSEARCH_API_KEY RapidAPI (JSearch) Edge Functions
Secondary search engine. Runs in parallel with SerpAPI for broader coverage across different job boards and sources. Complements the primary search.
rapidapi.com → JSearch API
Payments — Required for paid tiers
STRIPE_SECRET_KEY Stripe Server
Server-side Stripe SDK initialization. Creates checkout sessions, manages subscriptions (Pro $19/mo, Premium $39/mo), handles plan upgrades and downgrades.
STRIPE_WEBHOOK_SECRET Stripe API Routes
Verifies incoming webhook signatures. Ensures events (payment success, subscription changes, invoice failures) genuinely came from Stripe before the app processes them.
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY Stripe Client (public)
Client-side key that initializes Stripe checkout UI on the subscription page. Safe to expose — it can only create checkout sessions, not read data.
dashboard.stripe.com → Developers → API Keys
Observability — Recommended
LANGFUSE_SECRET_KEY LANGFUSE_PUBLIC_KEY LANGFUSE_BASE_URL Langfuse Edge Functions
LLM observability. Every AI call is traced with: agent type, user ID, duration, token counts (input/output/cache), cost estimate, and success/failure status. Feeds the admin dashboard's per-user cost table. Base URL defaults to https://cloud.langfuse.com.
cloud.langfuse.com
SENTRY_DSN Sentry Edge Functions
Error tracking. Captures exceptions in Edge Functions when pipeline jobs fail, AI calls error, or unexpected crashes happen. Surfaces in your Sentry dashboard for debugging.
sentry.io
Email — Required for email features
SENDGRID_API_KEY SendGrid Edge Functions
Sends outbound email digests — daily or weekly notification summaries to users with new matches, prepared applications, and status updates.
SENDGRID_WEBHOOK_SECRET SendGrid API Routes
Verifies inbound email webhooks for the email forwarding feature. Users forward job posting emails to Woodhouse, which parses them with Haiku and adds them to the pipeline.
sendgrid.com → Settings → API Keys
Configuration
ADMIN_EMAILS Server Actions
Comma-separated list of email addresses with admin access. These users can access /admin/pipeline (job monitoring, cost tracking) and /admin/settings (system configuration). Example: you@example.com,cofounder@example.com
NEXT_PUBLIC_APP_URL Client + Server
Your production domain (e.g., https://woodhouse.app). Used for email links, OAuth redirects, and webhook URLs.

Priority Order

Get things running incrementally:

  1. ANTHROPIC_API_KEY — nothing AI works without it
  2. ADMIN_EMAILS — your email, so you can access admin pages
  3. SERPAPI_API_KEY + JSEARCH_API_KEY — job discovery needs search engines
  4. STRIPE_* (3 keys) — billing; free tier works without these
  5. LANGFUSE_* (3 keys) — AI cost tracking and observability
  6. SENTRY_DSN — error monitoring
  7. SENDGRID_* (3 keys) — email digests and forwarding

3. Verification Checklist

Run through this end-to-end after all keys are in place:

  • Sign up — create a new account, verify redirect to onboarding
  • Onboarding — upload a resume (PDF or DOCX), verify parsing extracts data
  • AI Assist — test "Generate Summary", "Suggest Skills", and "Improve Achievement"
  • Discovery — trigger a discovery run, verify jobs appear in Job Feed
  • Evaluation — verify match scores appear on discovered jobs
  • Tailoring — click "Prepare Application", verify resume and materials generate
  • Review Queue — approve an application, verify files download
  • Tracker — verify approved application appears, drag between columns
  • Notifications — verify badge in sidebar and notification page
  • Stripe — test Pro upgrade via checkout (use test mode first)
  • Admin — access /admin/pipeline, verify dashboard loads with your admin email
  • Landing page — visit /, verify hero, pricing table, and CTAs

4. Post-Launch

Recommended

CI/CD Pipeline

GitHub Actions: lint, type-check, build, deploy on push to main.

Monitoring

Verify Langfuse traces for AI calls. Check Sentry for production errors.

Security Audit

Test RLS policies. Verify users can't access each other's data. No API key leakage.

Backups

Supabase handles daily backups. Verify retention settings in project dashboard.

Future Enhancements
